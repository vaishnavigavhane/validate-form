# ✅ JavaScript Form Validation

A responsive form validation project built using **HTML, CSS, and Vanilla JavaScript**.  
The application validates user inputs in real-time and prevents submission until all fields are correctly filled.

🔗 **Live Demo:**  
https://vaishnavigavhane.github.io/validate-form/

---

## 🚀 Features

- Validates required fields
- Checks minimum & maximum character limits
- Email format validation
- Shows real-time error messages
- Prevents invalid form submission
- Clean and responsive UI

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
